# ADR-0001 AI 只输出受约束的 JSON，不输出代码

- 状态：已采纳 · 2026-11-11

## 背景
生成式 UI 的常见做法是让模型直接写 React/JS 代码再执行。它灵活，但会出现无法运行的组件、无法审查的副作用和注入风险，也无法对“这次改了什么”给出可靠解释。

## 决定
模型只能输出 `protocol.md` 定义的 Proposal（create / patch / refusal）。系统用 Zod + 六层 Validator 校验，用预定义组件注册表渲染，用纯函数计算 Diff。

## 后果
- ✅ 安全边界清晰：协议里不存在任何能删除业务数据或执行代码的操作。
- ✅ Diff 可从前后两份定义精确计算，用户看到真实影响。
- ✅ 可测试：校验、应用、Diff 全是纯函数。
- ❌ 表达能力受组件库限制。对策：组件按“能力”而非“页面”设计（如 QuickAction 同时覆盖签到与借还）。
