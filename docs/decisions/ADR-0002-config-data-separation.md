# ADR-0002 配置与业务数据分离，版本只追加

- 状态：已采纳 · 2026-11-11

## 决定
- AppDefinition 存 `app_versions`（只追加）；业务记录存 `records`（JSON 列），二者无级联。
- 新增字段不回写旧记录，读取时按默认值**虚拟填充**。
- 恢复旧版本 = 新增一个内容等于旧版本的版本。
- 写记录时保留当前版本未知的旧键。

## 理由
这四条共同保证“配置回滚永远不会丢数据”，且无需任何数据迁移脚本。

## 代价
通用 JSON 存储不适合大规模查询；省赛数据量（≤ 几千条）下筛选在内存中完成。多实体关联与索引留到国赛。
