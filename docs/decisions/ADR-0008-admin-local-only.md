# ADR-0008 管理端默认仅本机访问

- 状态：已采纳 · 2026-11-11（随 ADR-0007 一起确认）

## 背景
服务端 `app.listen(port)` 监听全部网卡，而所有接口都不鉴权。在 v1 中这只是“局域网内谁都能看到全部数据”的隐患；引入角色视图（ADR-0007）后，它会直接架空视图的数据裁剪：拿到分享链接的人只要改一下地址，就能调用 `GET /api/apps/:id/records` 拿到含手机号的全部记录。

分享页需要被局域网内的手机访问（现场扫码报名、志愿者签到），所以不能只监听本机。

## 决定
1. 按来源区分两类接口：
   - **分享接口** `/api/v/:token/*`：任何来源可访问，由令牌与视图规则约束（protocol §11.4）。
   - **管理接口**（其余全部 `/api/*`，`/api/health` 除外）：默认只接受来自本机回环地址（`127.0.0.1`、`::1`）的连接，其他来源返回 `403 ADMIN_LOCAL_ONLY`，提示“管理功能仅限运行 MorphOS 的电脑访问”。
2. 判断依据是 TCP 连接的对端地址（`req.socket.remoteAddress`），**不读取** `X-Forwarded-For` 等可伪造的请求头。
3. 环境变量 `ADMIN_ACCESS=local|any`，默认 `local`。`any` 只用于自行加了外层鉴权的部署，启动日志会打印警告。
4. 前端静态资源对所有来源开放；管理页面在手机上打开时，接口返回 403，页面显示上述说明，而不是空白或报错堆栈。

## 后果
- ✅ 分享链接的数据裁剪不能通过改地址绕过（同一局域网内）。
- ✅ 现有接口测试经 Supertest 从回环地址发起，不受影响；新增测试模拟非本机来源。
- ❌ 放在反向代理后部署时，所有请求都显得来自本机，此保护失效；这类部署必须设 `ADMIN_ACCESS=any` 并自行加鉴权。README 与已知限制中写明。
- ❌ 组织者不能在自己的手机上使用管理端；省赛范围内接受，国赛再考虑管理口令或登录。
