## 记录规范

1. 每次 Claude Code 会话结束后，用 `/export` 导出完整对话，保存为 `NN-主题.md`（NN 为两位序号）。
2. 在文件顶部补一段元信息：日期、工具与模型、本次目标、关联提交 SHA、是否出现并修复了 Bug。
3. **提交前必须脱敏**：先保留不进入 Git 的私有原始副本，再在待公开副本上执行 `node scripts/redact-prompts.mjs`。现有脚本会原地替换匹配内容，且只覆盖部分 API Key / Bearer 模式，不能代替手机号、Cookie、分享令牌、截图和二维码的人工复核。pre-commit 也只是有限模式检查。
4. 不删改对话内容本身（脱敏除外）；AI 的错误回答与被纠正的过程正是评审要看的证据。
5. 无法导出的部分以截图或录屏补充，放在 `assets/`，并在本表登记。

## 脱敏规则与本次范围

| 类型 | 替换或处理 |
|---|---|
| 密钥、密码、Cookie、Authorization | 删除值，以 `[已移除：凭据类型]` 标记 |
| 分享链接和二维码 | 链接用 `/v/[分享令牌]`；二维码须人工遮挡或使用已失效的测试链接 |
| 真实参与者资料 | 稳定假名或 `[个人信息]`，避免前后引用错位 |
| 本机用户名、目录、内部地址 | 使用仓库相对路径或 `[项目目录]`、`[内部地址]` |
| 需求、失败、修改决策、测试结果 | 保留真实含义，删节有说明，不把预期写成实测 |
