# AI 协同过程记录（Prompt 历史快照）

> 对应比赛要求 2.1：至少 3 个核心功能迭代的完整 Prompt 链（提问 → AI 方案 → 引导修复 Bug 的过程）。
> 本目录只存**开发过程**中与 AI 编程工具的真实对话。产品内的 AI 操作记录存于应用数据库，二者不混用。

## 记录规范

1. 每次 Claude Code 会话结束后，用 `/export` 导出完整对话，保存为 `NN-主题.md`（NN 为两位序号）。
2. 在文件顶部补一段元信息：日期、工具与模型、本次目标、关联提交 SHA、是否出现并修复了 Bug。
3. **提交前必须脱敏**：`node scripts/redact-prompts.mjs`。仓库的 pre-commit 钩子也会拦截形如 `sk-…` 的字符串。
4. 不删改对话内容本身（脱敏除外）；AI 的错误回答与被纠正的过程正是评审要看的证据。
5. 无法导出的部分以截图或录屏补充，放在 `assets/`，并在本表登记。
