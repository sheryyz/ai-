# MorphOS 视觉与交互规范 v1

> 目标气质：**安静、精确、可信**。像 Linear / Vercel 一样克制，把视觉强调留给“AI 正在改变你的软件”这件事本身。

## 1. 原则

1. **内容优先**：运行界面是给真实用户用的工具，信息密度适中，不做装饰性渐变。
2. **AI 有专属语言**：凡是 AI 产出或待批准的东西，统一使用“变形色”（靛紫）与虚线描边；已生效的内容回归中性色。用户一眼分得清“哪些是 AI 提议、哪些已经生效”。
3. **变化必须可见**：每次批准后，新增组件以 layout 动画“生长”进来，修改项短暂高亮，移除项淡出。
4. **状态永远可感知**：任何等待都有分步进度；任何失败都说明原因与下一步。

## 2. 设计令牌（CSS 变量，亮 / 暗两套）

| 令牌 | 用途 | 亮色 | 暗色 |
|---|---|---|---|
| `--bg` | 页面背景 | `#FAFAFA` | `#0B0B0D` |
| `--surface` | 卡片 | `#FFFFFF` | `#141417` |
| `--border` | 分隔线 | `#E7E7EA` | `#26262B` |
| `--text` / `--text-muted` | 正文 / 次要 | `#18181B` / `#71717A` | `#EDEDEF` / `#8B8B93` |
| `--morph` | AI / 待批准 | `#6D5DF6` | `#8B7CFF` |
| `--add` | Diff 新增 | `#15803D` | `#4ADE80` |
| `--change` | Diff 修改 | `#B45309` | `#FBBF24` |
| `--danger` | 拒绝 / 风险 | `#DC2626` | `#F87171` |
| `--on-morph` | 变形色 / 危险色按钮上的文字 | `#FFFFFF` | `#0B0B0D` |
| `--overlay` | 对话框遮罩 | `rgb(9 9 11 / .32)` | `rgb(0 0 0 / .55)` |

- 字体：Inter Variable（拉丁与数字）+ 系统中文字体（PingFang SC / Microsoft YaHei）；Schema、Diff、JSON 使用 JetBrains Mono。字体通过 npm 打包，**不依赖 Google Fonts**（评委网络环境不确定）。
- 圆角 10px（卡片）/ 8px（控件）；阴影只用一层极浅阴影；间距 4 的倍数。
- 数字使用 `tabular-nums`。

## 3. 关键界面

| 界面 | 要点 |
|---|---|
| App Hub | 大输入框“描述你想要的应用”；下方模板卡片；应用卡片显示图标、记录数、当前版本、最后演进时间 |
| Studio 左栏 | 对话气泡；AI 回合内嵌**流水线步骤条**（理解 → 规划 → 生成 → 校验 → 自修复 → 就绪），当前步骤带呼吸点；思考内容可折叠流式展示 |
| Studio 中栏 | 运行时实时预览；待批准时以“幽灵层”叠加显示将新增的组件（虚线 + 变形色） |
| Studio 右栏 | Morph Diff 卡片：新增 / 修改 / 保留 / 影响 / 校验结果分组；底部固定“批准 / 继续修改 / 拒绝”；标签页切换版本时间线与 Schema |
| Runtime | 顶部应用名与简介；main 双列网格 + aside 侧栏；空状态有引导；表单提交即时反馈 |
| 拒绝提案 | 红色描边卡片，标出拦截层（如“L5 安全层”）、原因与建议改写，一键“按建议重试” |

## 4. 动效

- 时长 150–250ms，`ease-out`；尊重 `prefers-reduced-motion`。
- 变形：Motion `layout` + `AnimatePresence`；新增从 96% 缩放淡入，移除淡出。
- 数值变化（签到率）用数字滚动过渡。
