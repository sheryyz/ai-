# 验收用例

| 编号 | 操作 | 期望 | 自动化 |
|---|---|---|---|
| AC-01 | 自然语言创建活动报名应用 | 提案通过六层校验；批准后表单与表格可用 | 接口测试（离线样例）+ 手动（实时模型） |
| AC-02 | 新增记录后刷新页面、重启服务 | 记录仍在且字段值一致 | 接口测试 |
| AC-03 | 增量加签到字段 + 筛选 + 签到率 | 旧记录保留；新字段读出默认值 false；筛选与签到率正确 | 单测 + 接口测试 |
| AC-04 | 从零生成设备借用应用 | 仓库中不存在设备专用页面；能录入、借出、归还 | 代码检索 + E2E |

| AC-06 | 绑定形成环 | 拒绝，`GRAPH_CYCLE`，指出环上节点 | 单测 |
| AC-07 | 提案含 `deleteRecords` / `dropCollection` / `rawSQL` | 拒绝，`SAFETY_FORBIDDEN_OP`，记录数不变 | 单测 + 接口测试 |
| AC-08 | 提案 `baseVersion` 过期 | 拒绝，`VERSION_CONFLICT`，提示重新规划 | 单测 + 接口测试 |
| AC-09 | 批准后恢复旧版本，再恢复新版本 | 界面回退再前进；业务记录全程不变 | 接口测试 + E2E |
| AC-10 | 不配置 Key 启动 | 已有应用 CRUD、筛选、导出、历史正常；AI 输入框显示“未配置模型” | 接口测试 |
| AC-11 | 导出含中文的 CSV | Excel 直接打开不乱码；列与筛选一致 | 接口测试 |
| AC-12 | 按 README 从干净克隆启动 | 10 分钟内跑通 | 手动，录屏留证 |

| AC-14 | 删除字段 / 修改字段类型 | 拒绝，`SAFETY_DESTRUCTIVE_SCHEMA` | 单测 |
